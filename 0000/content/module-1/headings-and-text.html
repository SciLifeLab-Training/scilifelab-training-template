Headings and text

Use headings, paragraphs, and text formatting to organise your training content and make it easier for participants to read.

Each example below shows the Markdown syntax and how it appears when rendered.


Headings

Use headings to divide your page into sections and subsections. Quarto supports several heading levels:

  • ## Main section — appears in the table of contents.
  • ### Subsection — does not appear in the table of contents.
  • #### Sub-subsection — does not appear in the table of contents.

In this template, ## headings are displayed with a line underneath.

Markdown syntax

## Main section

Text introducing the section.

### Subsection

More detailed information.

#### Sub-subsection

Additional details.

Rendered result

Main section

Text introducing the section.

Subsection

More detailed information.

Sub-subsection

Additional details.

Use heading levels in order. For example, use ### for a subsection within a ## section, and #### for a subsection within a ### section.

Paragraphs

Write ordinary text as paragraphs. Leave a blank line between paragraphs.

Markdown syntax

This is the first paragraph. It introduces a topic or explains an idea.

This is the second paragraph. It appears separately from the first.

Rendered result

This is the first paragraph. It introduces a topic or explains an idea.

This is the second paragraph. It appears separately from the first.

Text formatting

Use bold and italic text to emphasise words or phrases.

Markdown syntax

This is **bold text**.

This is *italic text*.

This is ***bold and italic text***.

Rendered result

This is bold text.
This is italic text.
This is bold and italic text.
